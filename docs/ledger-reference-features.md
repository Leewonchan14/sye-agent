# 편한가계부 기능 리스트업 → sye-agent 공유 가계부 범위

참고 앱: **편한가계부 4.13.1** (Realbyte Inc., `com.realbyteapps.moneymanagerfree`).
Android 12(redroid) 에뮬레이터에 실제 설치해 가계부·통계·자산·더보기·설정관리 화면과 입력 화면을 직접 확인했다.

## 1. 실제 앱에서 확인한 기능

### 가계부(내역)

- 뷰 전환: **일일 / 달력 / 월별 / 결산 / 메모**
- 월 이동, 수입·지출·합계 요약, 전월 대비
- 필터: 수입 / 지출 / 자산 / 전체 / 이체입금 / 이체출금 / 현금 / 은행 / 카드
- 검색, 즐겨찾기, 내역 복사, 사진 첨부
- 빈 상태 안내

### 내역 입력

- 수입 / 지출 / **이체**
- 날짜·시간, **반복/할부**
- 금액 입력 + 계산기
- 분류(대분류/소분류), 자산(결제수단)
- 내용·메모·태그·사진
- 음성 입력(특허 출원), 내역 자동완성, 입력순서 설정, 즐겨찾기
- 카드 문자(SMS)·앱 알림 자동 등록

### 자산

- 자산 / 부채 / 합계
- 자산 그룹: 현금·은행·카드·저축·보험·대출·부동산 등
- 자산별 잔액, 자산 상세(일별/월별/연별)
- 카드 결제예정금액·미결제금액, 카드 이용실적(체리피커)
- 이체, 카드지출 반영방법(사용시점/승인시점)

### 통계·예산·결산

- 기간: 월간/연간/사용자 지정
- 수입/지출 토글, 분류별·자산별 차트
- 총 예산, 월별 예산, **분류별 예산**, 예산 진행률
- 결산: 예산, 자산, 전월 대비 지출, 현금/은행 지출, 카드 지출, 이체
- 엑셀 내보내기/가져오기, 메일로 내보내기

### 공유·동기화

- 계정 로그인 후 기기 간 동기화(사진 제외)
- **계정을 공유하면 부부가 함께 가계부를 공유/작성**
- PC 가계부(무료는 일부 기능·광고 포함, 유료/구독은 전체)

### 설정

- 주 화폐 / 보조 화폐, 월 시작일·주간 시작일, 이월 설정
- 스와이프 날짜 이동, 수입-지출 색상, 시간 표시
- 내역 메모 표시, 자동완성, 입력순서, 메모 버튼
- 비밀번호 잠금, 알림, 빠른 입력, 스타일(테마), 위젯, 언어
- 수입/지출 분류 관리, 소분류, 태그 관리, 반복 관리, 예산 설정
- 백업/복원(이메일·기기 저장·자동 백업), 공지/도움말/문의

### 부가

- 홈 화면 위젯(빠른 입력 3종, 카드 실적 위젯), 편한계산기, PC 가계부, 광고/구독

## 2. sye-agent에 구현한 범위

`/ledger` — 사이드바 **가계부** 탭. 두 사람(원찬·예은)의 **모임통장 전용** 가계부. 기록자와 다른 결제수단은 다루지 않는다. 기존 `member`, `asset_id` 컬럼은 과거 데이터 보존용으로 남기고, 새 기록은 `joint`와 `모임 통장`으로 저장한다.

| 영역   | 구현                                                                           |
| ------ | ------------------------------------------------------------------------------ |
| 내역   | 날짜·시각 순 그룹, 전체 기간 검색(내용·태그·분류), 추가·수정, 삭제 후 되돌리기 |
| 달력   | 월 그리드, 일별 합계, 고른 날짜를 새 내역의 기본 날짜로 사용                   |
| 통계   | 기간별 리포트, 실제 잔액 기준 추이, 분류별 지출, 큰 지출 TOP 8, 월 메모        |
| 잔액   | 시작 잔액 + 오늘까지 입금 - 지출, 실제 통장 잔액에 맞추기                      |
| 예산   | 월 총예산, 분류별 진행률, 이번 달 사용 속도, 지난달 예산 불러오기              |
| 입력   | 수동 입력, 은행 알림 붙여넣기(중복 건너뜀), 채팅으로 기록                      |
| 데이터 | CSV 내보내기, `ledger_entry_history` 변경 이력, 소프트 삭제                    |

채팅 연동: `/api/chat`이 턴마다 1시간짜리 가계부 전용 토큰과 사용법을 Hermes 지시사항에 넣는다. Hermes는 `/api/ledger/agent`를 `x-ledger-token`으로 호출한다. 이 토큰은 다른 API에서 쓸 수 없고, Hermes 쪽 설정은 필요 없다.

## 3. 이번에 제외한 것 (다음 단계 후보)

- 이체, 반복/할부, 고정지출
- 음성 입력, 사진 첨부, 문자 자동 수신
- 부채·카드 결제예정금액, 카드 실적
- 다중 통화/보조 화폐, 월 시작일·이월 설정
- 엑셀/CSV 가져오기, 백업/복원
- 비밀번호 잠금, 알림, 위젯, 테마, 다국어
- PC 전용 화면, 구독/광고
